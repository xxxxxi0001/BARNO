# Data
The full datasets used in this study are too large to be distributed directly in this repository. 
All genie weight files are provided (separately for CD4, CD8, Mel), which save time for you to run calculated weight by yourself~ 

## Original data source
SCP109:
https://singlecell.broadinstitute.org/single_cell/study/SCP109/melanoma-immunotherapy-resistance

Data I used for this study: 
* Mel: Mel.malignant.rds
* CD4: Mel.T.CD4.QC.rds
* CD8: Mel.T.CD8.QC.rds
* Validation: public.ICB.datasets.rds & TCGA_SKCM.rds

## All Data and Run Example (except original data set from SCP109) are archived in zenodo
